# 家庭票据盒

给家里收纳重要发票/小票的小工具。手机浏览器打开即用，可添加到桌面当 App；所有数据只存在本机浏览器（IndexedDB）里，没有账号、没有服务器、断网也能用。

## 功能

- 拍照 / 相册 / 文件上传发票（支持多张图片与 PDF，照片自动压缩）
- 分类（餐饮、交通、医疗、教育、住房、数码、购物、其他）+ 自定义标签
- 搜索：商家、备注、标签、金额都能搜；分类一键筛选
- 按月份归档，自动统计张数与总金额
- 备份导出 / 导入（JSON，含全部图片），右上角「⋯」菜单里
- 离线可用（PWA），添加到桌面后像原生小程序

## 在手机上使用

1. 启动：在本目录执行 `python3 -m http.server 8080`
2. 手机连同一 Wi-Fi，浏览器打开 `http://<电脑IP>:8080`
3. iPhone：Safari → 分享 → 添加到主屏幕；安卓：Chrome 菜单 → 添加到主屏幕

查看电脑 IP：`ipconfig getifaddr en0`（macOS）。

## 注意

- 清理浏览器数据会连票据一起清掉，请偶尔「导出备份」存一份。
- 纯静态、零依赖，部署到任意静态托管（需 HTTPS 才能启用离线缓存）也可以。
